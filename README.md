## 🧩 Featured Projects

**Material — Marketplace for Posters by Independent Designers**

A full-stack project built solo end-to-end — schema, API, image pipeline, storefront and designer cabinet — from a design concept at Protothon 2024 to a working MVP:
- Catalog with filtering by category, colour, orientation, price and author; sizes and framing priced per available print resolution
- Guest cart with account merge on sign-in; checkout via pickup, courier or post
- Designer studio: upload, moderation, per-size pricing, sales & payouts dashboard
- Shared domain package for pricing, sizing and order rules — client and API always agree
- 900 tests total (274 domain, 409 API, 217 client)

Stack: React, Vite, Express, PostgreSQL, TypeScript (shared domain package)
🔗 [github.com/everythingiam/marketplace](https://github.com/everythingiam/marketplace) ·🚀 [Live demo](https://material-posters.fly.dev/)
