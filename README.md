## 🧩 Projects

**Dany — Real-time Multiplayer Browser Game**

A full-stack project built solo:
- Real-time multiplayer over WebSocket (chat, live card canvas, synced game state)
- Game logic implemented in PostgreSQL + Node.js server
- Session-based auth with hashed passwords and cookie tokens
- Interactive card canvas with fabric.js, state synced across clients in real time

Stack: React, Node.js, PostgreSQL, Socket.io, MobX
